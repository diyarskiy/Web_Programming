# Rick and Morty multiverse
The Larpers · SE-2510

[Website](https://diyarskiy.github.io/Web_Programming/) · [Repository](https://github.com/diyarskiy/Web_Programming)

Run the site using Live Server or a local HTTP server. The six pages share navigation and a saved light/dark theme.

- Home introduces the guide and includes a subscription form.
- Characters lets visitors search by name or occupation.
- Multiverse includes a searchable location guide and portal picker.
- Adventures lets visitors plan a trip and pick an episode from TVmaze.
- Account simulates signup and login in the browser.
- Profile displays the signed-in traveler's ID and contact details.

Accounts, the signed-in traveler, and theme preferences are stored in localStorage on the current browser. JavaScript validates forms and displays errors on the page. Episode data, external character images, Bootstrap, and jQuery need an internet connection.

Styles are in CSS/, scripts in js/, artwork in images/, and audio in sounds/.
